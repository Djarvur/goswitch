Коллеги, представляю свой проект goswitch — корректор текста, набранного
не в той раскладке (EN ↔ RU), и переключатель раскладки для GNOME Wayland.

Предыстория короткая. Apple прекратила поддержку Intel-макбуков, и мне
пришлось срочно менять операционную систему. Выбор пал на Ubuntu, и на
моём MacBook (i7, 64 ГБ оперативной памяти) Linux работает даже лучше,
чем последняя macOS. Не хватало одного инструмента: на macOS я годами
пользовался Caramba Switcher, который сам исправляет текст, набранный не
в той раскладке. Аналога для Linux не нашлось — ни собственными силами,
ни с помощью ИИ, — поэтому я написал его сам. Весь код создан с помощью
ИИ: большая часть — GLM 5.3 Flash, сложные места — GLM 5.3.

Что умеет goswitch:

- исправить по горячей клавише слово, целую фразу или выделенный
  фрагмент, набранные не в той раскладке (ghbdtn → привет);
- опциональную автокоррекцию без горячей клавиши (по умолчанию выключена);
- переключение раскладки по горячей клавише.

Технически: IBus input method engine в пользовательской сессии — без
root, без перехвата клавиатуры на уровне evdev, поэтому не конфликтует с
keyd/xremap. Лицензия MIT, установка и удаление одной командой.

Честное ограничение: значительная часть современного софта построена на
X-протоколе поверх Wayland — в таких приложениях поля ввода недоступны, и
автокоррекция там по большей части не работает.
