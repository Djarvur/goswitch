## Context

SPEC §11 (spec-delta 06-01) — источник требования, дословно:

> Решение владельца (2026-09-27, D-51): автокоррекция возвращена строго на
> предписанных ею же условиях — отдельной опцией, default off, с white/black
> list по классам окон. Она открывает milestone v1.1.0 (в объём v1 не входит).
> Механика возврата — ADR-007: гибридный детектор (словарный путь + триграммный
> fallback), роль AT-SPI как источник решения — живой GetRole в момент решения,
> fail-closed политика (любое «неизвестно» → молчание).

Решения владельца (06-CONTEXT фазы 06, дословно):

> **D-52:** Гибридный детектор, решение владельца 2026-09-27: (а) словарный
> путь — на границе слова «набранное слово НЕ в словаре текущей раскладки И
> его ремап по таблице ЙЦУКЕН↔QWERTY ЕСТЬ в словаре другой» → высокая
> уверенность ошибки; (б) триграммный скоринг как fallback для OOV-слов
> (имена, опечатки) — сравнение правдоподобия слова в обеих раскладках.
> Доноры: xneur (GPL — ТОЛЬКО референс алгоритма, goibus-прецедент, код не
> копируется), Easy Switcher (GPL-2.0-only — тоже только референс), whatlanggo
> (MIT — допустим как зависимость; финальное решение «своя мини-модель vs
> зависимость» — за research по размеру/аудиту). Словарные данные (hunspell
> ru/en, частотные списки) запекаются go:generate-генератором в golden-паттерне
> таблиц Фазы 1; лицензии конкретных источников проверяет research ДО выбора.

> **D-53:** Политика срабатывания — конъюнкция ВСЕХ условий: (1) приложение
> в white-list политики (по bridge-namespace из internal/appid), (2) роль
> сфокусированного AT-SPI-объекта — текстовый ввод (entry/document text; НЕ
> password text, НЕ terminal, НЕ canvas), (3) приложение отдаёт surrounding
> text (verify-rung применим), (4) детектор дал уверенный вердикт, (5) слово ≥
> минимальной длины. ЛЮБОЕ «неизвестно» (нет AT-SPI-дерева, нет фокус-события,
> роль неопределима) → молчание. Роль запрашивается живым GetRole по объекту из
> фокус-события В МОМЕНТ решения — кэш appid (последнее известное приложение)
> advisory, не основание для срабатывания.

> **D-54:** Default off везде: конфиг-секция `autocorrect` в YAML-схеме (strict
> decode D-33, hot reload D-32 распространяются автоматически), вшитые дефолты —
> enabled: false + пустой white-list. goswitchctl status показывает состояние
> автокоррекции (enabled/политика/последние счётчики срабатываний — аналогично
> MACRStats). Публичный конфиг-контракт docs/CONFIG.md дополняется.

> **D-55:** SPEC правится spec-delta внутри фазы ДО кода детектора (ADR
> нумерация обновлена: 006→007): §2 (класс 3 больше не «вне объёма»), §10
> (снять пункт), §11 (записать решение возврата: opt-in, default off,
> white/black list — как предписано; новая дата решения владельца). ADR-007
> (ренумерован с 006) — механика: AT-SPI роль источником решения, отказ от
> кэш-семантики, лицензионная позиция по донорам.

## Decision

### (а) Словарный путь — чем проверять «слово существует»

| Кандидат | Вердикт | Обоснование |
|---|---|---|
| xneur-подобные regex-списки (8–9 строк/язык — прочитано вживую, `detection.c`) | **Отклонён** | Словари xneur — крошечные списки однозначных коротких слов; реальное покрытие делегировано опциональному enchant/aspell — для нас это рантайм-зависимость и неполнота там, где полнота = безопасность. |
| Полноценные hunspell-словари ru_RU + en_US, запечённые go:generate-генератором (golden-паттерн таблиц Фазы 1) | **Принят** | Полнота = безопасность: каждый словарный hit ПОДАВЛЯЕТ коррекцию. ru 146 261 / en 78 951 слов; +7.9 МБ бинарника (измерено), вшитый sorted-срез живёт в rodata ≈ 0 кучи — бюджет SPEC §5 (< 50 МБ) держится. Лицензии чистые — см. (д). |

### (б) Триграммный fallback для OOV-слов (D-52б)

| Кандидат | Вердикт | Обоснование |
|---|---|---|
| whatlanggo (MIT, zero-dep) | **Отклонён ТЕХНИЧЕСКИ** | Юридически MIT допустим; отклонение по размеру/профилю задачи: +747 КБ бинарника (измерено), 1 918 LOC аудита, профили под 84 языка и предложения — на слове 2–10 символов (0–8 триграмм) уверенность деградирует; заморожен с 2019. |
| Своя мини-модель на тех же hunspell-данных | **Принят** | ~50–80 LOC + десятки КБ сгенерированных таблиц; ноль новых зависимостей; полный аудит; пороги θ_diff/θ_abs и минимальная длина слова пинируются обязательным golden-корпусом (включая OOV-имена, ё-слова, mixed-токены). |

### (в) Источник роли — чем подтверждать «текстовый ввод» (D-53)

| Кандидат | Вердикт | Обоснование |
|---|---|---|
| Кэш приложения (MACR-семантика ADR-005: последнее известное приложение) | **Отклонён как основание решения** | Кэш сталеет: фокус на приложении без AT-SPI-дерева (wezterm вообще вне шины — живой факт) унаследовал бы чужую роль. D-53 прямо запрещает; кэш appid остаётся advisory. |
| Живой GetRole по (sender, path) фокус-события В МОМЕНТ решения | **Принят** | Форма вызова верифицирована живьём (`org.a11y.atspi.Accessible.GetRole` по пути бриджа отвечает мгновенно из любого a11y-соединения); round-trip по unix-сокету ≈ доли мс на границе слова — бюджет SPEC §5 не под угрозой. Сравнение ТОЛЬКО по enum-числу GetRole (40=password text, 60=terminal, 61=text, 79=entry, 94=document text) — имена-строки расходятся между биндингами («text box» vs «text»). |

### (г) Деградация при «неизвестно»

| Кандидат | Вердикт | Обоснование |
|---|---|---|
| fail-open MACR (деградация к глобальному правилу с WARN, ADR-005) | **Отклонён — направление инвертировано** | MACR-подмена видимая и командная; автокоррекция молчаливая — ложное срабатывание стоит паролем или кодом. Ранг «деградация к глобальному правилу» в автокоррекцию НЕ переносится. |
| fail-closed: ЛЮБОЕ «неизвестно» → молчание | **Принят** | D-53 дословно: нет AT-SPI-дерева / нет фокус-события / роль неопределима / caps нет / детектор не уверен / слово короче минимума → ключ транзитит, ничего не происходит. Из MACR переносится только warn-once-паттерн эпизода (один WARN на эпизод деградации, не на клавишу). |

### (д) Доноры и словарные данные — лицензионная позиция

| Кандидат | Вердикт | Обоснование |
|---|---|---|
| xneur (GPL-2+), Easy Switcher (GPL-2.0-only) как код | **Запрещено копировать** | НИ СТРОКИ кода в MIT-репо — goibus-прецедент (нет/чужая лицензия = нельзя шипить). Только чтение алгоритма read-only; кодовые планы фазы не имеют GPL-источников в read_first — только пересказ research. |
| hunspell ru_RU (custom-BSD Lebedev, пункт 4 снят) / en_US (SCOWL permissive) как данные | **Принято — запекаются** | Генератор строит golden-срезы с сохранением копирайт-нотисов (файл данных/доки); обе лицензии совместимы с MIT при атрибуции. Частотники OpenCorpora НЕ используются (лицензия неверифицирована — A1). |
| whatlanggo как Go-зависимость | **Отклонён технически** (см. б) | MIT допустим юридически — вердикт по размеру/профилю, не по праву. |

## Consequences

- Обязательства фазы (все кодовые планы 06-02..06-07):
  - конфиг-секция `autocorrect` — strict decode, вшитые дефолты `enabled: false` +
    пустой white-list (D-54); hot reload/strict-decode D-32/D-33 распространяются
    автоматически; docs/CONFIG.md дополняется;
  - счётчики срабатываний с причинами (словарный hit / fallback / отказ) — в
    `goswitchctl status` по образцу MACRStats; **само слово — НИКОГДА** ни в
    логах любого уровня, ни в статусе (приватность строже D-20/D-21: DEBUG-запись
    source/result командной коррекции в автокоррекцию не переносится — слово
    может быть паролем);
  - e2e-негативы обязательны: парольное поле GTK4 (роль `password-text` = 40) и
    терминал (wezterm вне a11y-шины) — оракулы «текст не изменился» / счётчики = 0;
  - детектор — чистый пакет без D-Bus, часов и горутин; замена текста — только
    существующий конвейер plan → verify → ladder `internal/correct`, никакого
    второго механизма.
- Живой факт-ограничение — **роль necessary-not-sufficient**: GTK3-пароль
  (zenity --password, GtkEntry visibility=off) отдаёт роль 61 «text box» —
  неотличимую от обычного текстового поля (живая верификация Q4 на GNOME 46).
  Ролевый гейт GTK3-пароли НЕ ловит; безопасность держится на конъюнкции D-53
  в целом: white-list приложений (default пуст = выключено везде) + роль +
  surrounding-text + уверенный вердикт детектора + минимальная длина слова.
- Честная поправка по донорам: референс Easy Switcher прочитан целиком —
  **словарного алгоритма он не содержит** (ручной корректор по клавише: буфер
  сканкодов + ReplaceWord; премисса D-52 о нём как о «словарном референсе» не
  подтверждается — Q1b). Подтверждена только нижняя граница «слово < 2 символов
  не трогаем»; донорские уроки детектора даёт xneur.
- Perf-измерение (Pitfall 5, план 06-08, 2026-10-02, одна сессия, ~4 минуты
  между прогонами, N=40, окно ydotool→AT-SPI — методика 04-04/04-07 дословно,
  жест не менялся: тот же комбо-аккорд, включённая фича). Полные отчёты —
  `mise run e2e-perf` / `mise run e2e-perf-autocorrect` (perf-report.txt):

  | Прогон | p50 | p95 | p99 | VmHWM |
  |---|---|---|---|---|
  | baseline — встроенные дефолты (без -config) | 169.3 мс | 180.2 мс | 180.4 мс | 19.8 МБ |
  | autocorrect ON — white-list org.gnome.Zenity, пороги 4/2.0/1.0 | 169.6 мс | 176.9 мс | 177.5 мс | 19.1 МБ |
  | **дельта** | +0.3 мс | **−3.3 мс** | −2.9 мс | −0.7 МБ |

  Гейт плана (дельта p95 ≤ +5 мс): **ПРОЙДЕН** — включённый слой не смещает
  хвостовую латентность (дельта отрицательна, в пределах шума прогона;
  решение на границе слова живёт вне пути клавиши — armed-payload handoff
  06-06). Абсолютный бюджет-фейл окна (p95 ≈ 180 мс ≥ 50 мс) —
  санкционированный честный исход 04-07 (WINDOWS #5): окно доминировано
  инжектором стенда (ydotool 0.1.8, ~170 мс/аккорд), реакция демона на аккорд
  суб-миллисекундная; память — с широким запасом.

## Reversibility

Оценка по D-51/D-52 дословно: **«отдельной опцией, default off»** — фича
выключена по умолчанию и отключается одним конфиг-ключом (white-list default
пуст — даже включённая секция без явных приложений ни в кого не стреляет).
Словарные и триграммные данные регенерируются генератором из системных пакетов.
До перевода в Accepted (план 06-08) решение обратимо редактированием этого
документа и spec-delta; после — дёшево: выключение ключом конфига без правки
кода.
