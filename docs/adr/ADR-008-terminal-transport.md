# ADR-008: Терминальный транспорт — чтение, запись, клип-политика и точка аборта ручной коррекции в терминалах

## Status

**Proposed** — решение о терминальном транспорте зафиксировано ДО живого
спайка (D-55: спека прежде кода); ячейки Evidence пусты. Переводится в
**Accepted** планом 09-03 (фикс wezterm + two-greens оракул) на
свидетельствах журнала спайка `adr-008-spike-log.md` — построчными
ссылками, не ранее. Ни одна строка решений D1–D7 не считается решённой
до живых свидетельств: ячейки заполняются ТОЛЬКО ссылками на строки
журнала спайка, никогда веб-источниками (анти-паттерн «фикс из
issue-tracker'а»: апстрим-факты упоминаются в Context без ссылок; ссылки
живут только в журнале спайка как контекст).

Нумерация: ADR-008 — следующий свободный номер за ADR-007.

## Context

**1. Дефект wezterm — гипотеза первопричины (HIGH локальной уверенности,
НЕ вердикт).** Конфиг владельца `~/.wezterm.lua` ставит
`enable_wayland = false`; wezterm 20240203-110809-5046fc22 (последний
тегированный релиз — апстрим на nightlies с февраля 2024) работает как
XWayland/XIM-клиент. При двухдвижковой схеме ADR-006 флип
(`SetGlobalEngine`) меняет движок демона, но не X-keymap XIM-клиента:
клиент резолвит символы по X-keymap, который при флипе не меняется, —
переключение структурно невидимо для такого клиента. Это гипотеза, а не
вердикт: три конкурирующих класса разрыва различает лестница проб
P0–P5 (09-RESEARCH, Pattern 1) —

- **h1 — армирование**: ключи не доходят до движка (мёртвый IM-контекст);
- **h2 — перечеканка движка**: флип-пара focus_out/focus_in не приходит
  для wezterm-контекста (re-mint churn);
- **h3 — доставка commit**: демон коммитит кириллицу, но в pty падает
  латиница (XIM-доставка коммита сломана).

Лестница: P0 transport identity (`WAYLAND_DISPLAY`/`DISPLAY` в
`/proc/<pid>/environ`, `xlsclients`) → P1 доставка ключей (`-debug`
трейс демона) → P2 флип-пара в журнале → P3 CommitText на проводе
(`dbus-monitor`/счётчики демона без содержимого) → P4 байты в pty
(земля: `cat > file`, hexlify) → P5 raw-keymap путь в окне гонки
армирования. Вердикт-матрица перевода P-исходов в класс разрыва —
в 09-RESEARCH (Pattern 1); строки вердиктов пишет живой спайк в журнал.

**2. Вопрос транспорта терминалов.** Коррекция в терминалах (слово —
обязателен, строка — feasibility-gated; rev D-55 SPEC §4.3/§4.4) требует
ответов, которых у демона сегодня нет: чем ЧИТАТЬ набранное (терминалы
не дают surrounding text: wezterm вне a11y-шины; VTE ложно анонсирует
surrounding text — доверять caps нельзя, тождество/роль первичны), чем
ЗАПИСЫВАТЬ исправление (BackSpace-реплей? commit поверх выделения?
paste-чорд?), что происходит с буферами обмена, где точка безопасного
аборта, каков контракт объёма. Эти ответы гейтят Фазу 10 (слово,
TERM-02) и Фазу 12 (строка, TERM-03).

**3. Рамка — двухразрешительная модель (rev D-55 SPEC §11).** Ручная
коррекция в терминалах разрешена; автокоррекция никогда не армируется
в контексте терминала (роль AT-SPI 60 или терминальная identity; вето
живёт в точке армирования, не в blocklist). ADR-008 определяет только
транспорт РУЧНОЙ коррекции; автокоррекционный контур ADR-007 терминалов
не касается и в терминалах молчит по инварианту.

**4. Живой факт 2026-10-08 (решение владельца):** внешний инжекторный
путь (uinput-инжекторы вне демона) на рабочем столе владельца не
работает — гонка за фокусом; демонский канал (IBus ForwardKeyEvent +
commit_text) от неё свободен. Это сужает поле вариантов D1 (см. Decision)
до фактического единственного кандидата — но формально варианты
сохраняются в таблице до свидетельств.

Апстрим-факты, упоминаемые без веб-ссылок (ссылки появятся только в
журнале спайка как контекст, не как свидетельство): 20240203 — последний
тегированный релиз wezterm; нативный Wayland-транспорт (zwp_text_input_v3)
этой сборкой поддержан; известные ловушки сборки — #5125 (IME с IBus,
класс нативного режима), #1772 (text-input-v3 quirks), #4615 (потеря
модификаторов на форварднутых чордах). Ни одна из них не служит
обоснованием строки решений — только чекпоинт-рядом спайка.

## Decision

Ни одна строка ниже не считается решённой до живых свидетельств спайка:
каждая Evidence-ячейка — пустой плейсхолдер с именем журнала
`adr-008-spike-log.md` (файл создаёт план 09-02, ячейки заполняет 09-03).
Ячейки заполняются только ссылками на строки журнала, никогда
веб-источниками.

| Решение | Варианты | Evidence (живой спайк) |
|---|---|---|
| D1 Транспорт на терминал — собственный канал демона: ForwardKeyEvent для клавиш (чорды выделения, реплей BackSpace) + commit_text для замещающего текста; внешние инжекторы и paste-чорды в демоне отвергнуты (вне демона — гонка за фокусом, живой факт 2026-10-08; paste-чорд в терминале — Ctrl+C-класс SIGINT-риски) | (а) демонский канал ForwardKeyEvent + commit_text; (б) внешний инжектор — отвергнут живым фактом; (в) paste-чорд — отвергнут по построению | (spike: строки P1/P3/P4 журнала adr-008-spike-log.md, терминал wezterm + VTE — доставка ключей, коммит на проводе, байты в pty) |
| D2 Ветка фикса флипа wezterm — рецепт нативного Wayland-режима первым (stand-owned config с `enable_wayland = true` доказывает зелёным P0–P4 до всякой правки `~/.wezterm.lua`); демонский фолбэк — только если рецепт откажет (фундамент уже в коде: feedKey modeRU consume+commit — software keymap); апгрейд билда — отдельное решение владельца (20240203 = последний тег, nightlies-only дальше) | (а) config-рецепт нативного Wayland; (б) демонский фолбэк (pre-arm / re-arm on focus_in / ремонт доставки коммита — по классу разрыва h1/h2/h3); (в) bump билда — только владелец | (spike: строки P0–P5 журнала adr-008-spike-log.md, терминал wezterm, обе конфигурации — вердикт-матрица первопричины целиком) |
| D3 Канал чтения на терминал — wezterm: выделение по CopyMode-рецепту (config-рецепт) → `wl-paste --primary -n`; VTE: только собственный буфер нажатий демона (keyboard-selection в VTE нет — source-verified; дешёвый shortcut-check: флип→RU→набор→pty уже даёт кириллицу без канала чтения — слово почти бесплатно буфером+commit) | (а) wezterm: CopyMode-рецепт + PRIMARY read-back; (б) VTE: daemon-буфер нажатий; (в) единый примитив захвата строки — не существует, вопрос закрыт | (spike: строки select-chord (оба канала) + shortcut-check журнала adr-008-spike-log.md, терминал wezterm + VTE) |
| D4 Примитив записи — N×BackSpace реплей по числу буферных знаков + commit_text заменяющего текста; НИКОГДА commit-over-selection (терминальные выделения визуальны — коммит поверх их не заменяет) и НИКОГДА paste-чорд (Ctrl+C = SIGINT) | (а) BackSpace-реплей + commit_text; (б) commit-over-selection — отвергнут; (в) paste-чорд — отвергнут | (spike: строки commit-landing + форвард-бурста журнала adr-008-spike-log.md, терминал wezterm — sanity модификаторов на форварднутых бурстах, ловушка #4615) |
| D5 Клип-политика — PRIMARY-only; CLIPBOARD байт-нетронут (демон никогда не пишет и не читает CLIPBOARD в терминальном пути); флаг `-n` везде (trailing-newline ловушка); судьба затёртого копи-он-селектом PRIMARY (save/restore против честной документированной оговорки) — решает спайк-проба, какой чорд что затирает | (а) PRIMARY-only, CLIPBOARD нетронут, затирание задокументировано; (б) save/restore PRIMARY перед чордом — по свидетельству | (spike: строки sentinel-проб журнала adr-008-spike-log.md, терминал wezterm + VTE — какие выделения каждый чорд перезаписывает) |
| D6 Точка безопасности/аборта — бесплатный откат до первого отправленного BackSpace; после — one-way реплей + commit; verify-after логирует расхождение и останавливается, НИКОГДА не «чинит» сам (терминал = команды; слепая достройка командной строки недопустима) | (а) abort до первого разрушающего действия + verify-after без самолечения; (б) авто-самолечение после аборта — отвергнуто по построению | (spike: дизайн-строка D6, закреплённая свидетельствами D1–D4 журнала adr-008-spike-log.md, — отдельной пробы не требует) |
| D7 Контракт объёма — интерактивные шеллы bash/zsh в контракте; канонический режим и TUI-приложения вне контракта (три разные семантики стирания; BackSpace-как-команда) | (а) шеллы bash/zsh в контракте, канонический режим/TUI вне; (б) весь терминал в контракте — отвергнуто как небезопасное | (spike: строки shortcut-check + свидетельства D1–D4 журнала adr-008-spike-log.md, терминал wezterm + VTE, шелл bash/zsh) |

## Consequences

Для Фаз 10/12 этот ADR фиксирует (после перевода в Accepted):

- каналы чтения/записи на терминал (D1/D3/D4) — Phase 10 (TERM-02)
  проектирует word-чорд и семантику буфера на них, не переоткрывая;
- kill-критерий строки (D3/D7): если select-chord пробы фиксируют
  отсутствие примитива захвата строки (ожидаемо для VTE —
  keyboard-selection отсутствует), область строки честно сужается до
  wezterm; вердикт о сужении — за владельцем (TERM-03);
- клип-политику (D5): CLIPBOARD неприкосновенен — контракт публичного
  поведения демона;
- точку аборта и verify-after-семантику (D6) — контракт безопасности
  терминального пути.

За живым спайком (планы 09-02/09-03) остаётся:

- фактическое содержимое всех Evidence-ячеек — построчные вердикты
  журнала `adr-008-spike-log.md`;
- вердикт-матрица первопричины wezterm (P0–P5) и выбор ветки D2;
- развилка D5-б (save/restore PRIMARY против документированной оговорки);
- keep-or-remove debug-глагола probe-forward — гейт владельца на фазе,
  ADR не предрешает.

Ничего из этого ADR не предрешает: Proposed-статус с пустыми ячейками —
честный гейт; переоткрытие решений D1–D7 после Accepted — новая
датированная ревизия/амендмент этого документа, не тихая правка кода.

## Reversibility

**Proposed — обратим целиком** редактированием этого документа до всяких
свидетельств (план 09-03 переводит в Accepted только при заполненных
ячейках журнала). После Accepted: D5 (клип-политика) и D6 (аборт) —
контракты поведения, смена = новая датированная ревизия; D2 — обратим
самим выбором ветки до кода фикса; D4 — кодовый дизайн Фазы 10, до кода
меняется свободно.
