## Материал — история (по расшифровке)

- Apple прекратила поддержку Intel-макбуков → пришлось срочно переходить
  на другую ОС.
- Windows «не очень люблю с давних времен»; Linux «люблю еще меньше, но
  всё, что меня не убивает, делает меня крепче» → решил поставить Linux.
- «Взял в руки Ubuntu и Wayland» — и «в некотором смысле получилось»:
  Linux работает на его MacBook **даже лучше, чем работала последняя
  macOS**.
- Машина не мусорная: **i7, 64 ГБ оперативной памяти** [размер диска в
  расшифровке невнятен — НЕ указывать, владелец добавит сам], «вполне
  нормальная, даже по современным меркам машина» — её просто вывели из
  поддержки.
- Привык к инструментам macOS, в частности **Caramba Switcher**
  (написание проверено: caramba-switcher.com, автор Sergey Moskalev) —
  на ARM-макбуке продолжает им пользоваться; для Linux его не существует.
- «В процессе создания этого продукта я понял, почему»: Linux — «крошево
  технических решений», создавать под него продукт довольно трудно.
- Поискал интернет сам и с помощью ИИ — «ничего похожего в Linux-системе
  сегодня нет» → решил построить сам. «И построил.»
- «Важно понимать, что в код я, конечно, не глядел. Весь код написан с
  помощью искусственного интеллекта, фактически большая часть — с помощью
  GLM 5.3 Flash, но некоторые вещи, которые Flash-модели плохо давали,
  сделаны с помощью GLM 5.3.» [имена моделей дословно из расшифровки]
- Проект «нравится и закрывает основную проблему»: коррекция неправильного
  слова или даже фразы, набранных в неправильной раскладке.
- «Переключение [раскладки] в проект тоже добавлено, но, по-моему, работает
  оно не очень хорошо» — прежде всего потому, что большая часть ПО, которым
  владелец пользуется, «построено на каких-то грязных хаках и устаревших
  технологиях, в частности на X-протоколе поверх Wayland», поэтому
  «нормально получить доступ к полям ввода невозможно» → автокоррекция по
  большей части не работает (в таких приложениях).
- «Тем не менее, вы можете её пробовать, она существует, и присылайте ваши
  патчи, если вам кажется, что можно сделать лучше.»

## Корректировка владельца 2026-11-08 (после ревизии 2)

Владелец уточнил факт дословно: «переключение раскладки работает
прекрасно, плохо работает автокоррекция». Формулировка расшифровки
«переключение … работает не очень хорошо» — артефакт устной речи: «не
очень хорошо» относилось к автокоррекции, не к переключению. README
RU/EN (и любые производные тексты) обязаны это отражать: переключение —
прекрасно, автокоррекция — плохо (X-протокол поверх Wayland закрывает
доступ к полям ввода).
