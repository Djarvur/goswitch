## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| session-bus peers → /StatusNotifierItem + /Menu | Any same-uid session peer can read item/menu properties and DRIVE Event/Activate — the menu exposes toggle/status/reload actions; D-Bus SO_PEERCRED isolation bounds callers to the daemon's uid (the ctlsvc T-03-06-04 precedent) |
| StatusNotifierWatcher → daemon | The daemon consumes the watcher's registration replies, the RegisteredStatusNotifierItems property, and NameOwnerChanged broadcasts on the session bus |
| daemon → notification daemon | The status menu item posts a notification whose content is built from the actor's status snapshot |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-FG3-01 | Tampering | menu Event dispatch / item Activate | medium | mitigate | Same-uid session-bus isolation bounds callers (T-03-06-04); the actions mirror powers the ctl surface already exposes (CorrectNow/ReloadConfig) — no new capability; every dispatch opens with a recover shim so a panic below a click can never kill the daemon (recoverMethod precedent) |
| T-FG3-02 | Denial of Service | supervisor check() watcher round trips | medium | mitigate | Tick-paced (~30s constant) and event-paced, never a tight loop — a failed re-attach waits for the NEXT beat; godbus calls are bounded by the client's default call timeout, and the loop's channel receives stay unblocked between beats; log discipline prevents unbounded journal growth |
| T-FG3-03 | Information Disclosure | status notification content | low | accept | Body carries mode + version only (counts/states canon, T-03-06-03) — no user text, no config content; the notification daemon is a same-session, same-uid surface |
| T-FG3-04 | Denial of Service | godbus dispatch re-entering item/menu state | low | mitigate | Item and menu state guarded by their own small mutexes; no path from indicator/menu back into the actor except the quick ToggleMode/flipTo contract (queued sends, no round trips on the observer path); -race gates every iteration |
| T-FG3-05 | Tampering | a squatter owning org.kde.StatusNotifierWatcher | low | accept | The daemon only probes presence and registers; the item serves static properties (no secrets); a hostile watcher can at most waste the registration — same-uid boundary applies |
</threat_model>
