<objective>
MACR-01 по ADR-005: замена Super+Буква → Ctrl+Буква. Спайк Task 1 закрывает живую неизвестность доставки Super+буква (A7) до встраивания; Task 2 — перехват в feedKey выше mode-ветвей с consumed-upstream детектом; Task 3 — опциональный per-app AT-SPI-наблюдатель со лестницей деградации (A4). Всё за конфигом macr.* (схема 03-02), дефолт выключен.

**As a** пользователь приложений, где системные Super-шорткаты не работают, **I want** чтобы goswitch превращал Super+Букву в Ctrl+Букву в выбранных приложениях, **so that** линукс-порты с cmd-мышечной памятью становятся управляемыми — без keyd и root.

Purpose: MACR-01 — последнее крупное требование фазы; ADR-005 (M0 Accepted) задаёт механизм и деградацию.
Output: MACR-ветка актора с consumed-upstream счётчиком, internal/appid (spike-gated), кейсы macr-probe / macr-super-letter.
</objective>
