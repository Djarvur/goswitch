## Границы слова

| Option | Description | Selected |
|--------|-------------|----------|
| Да, исправлять | Punto-поведение: буфер помнит последнее слово и после пробела | ✓ |
| Нет, только до пробела | Пробел «отправляет» слово: после него двойной тап ничего не делает | |

**User's choice:** Да, исправлять
**Notes:** `ghbdtn <space>` → тап-тап → `привет <space>`.

| Option | Description | Selected |
|--------|-------------|----------|
| Не входит | Заменяется только буквенно-цифровая последовательность: `ghbdtn,` → `привет,` (запятая не трогается) | |
| Входит | Заменяется весь токен до пробела целиком одним диапазоном | ✓ |

**User's choice:** Входит
**Notes:** Согласуется с принципом границ (следующий вопрос).

| Option | Description | Selected |
|--------|-------------|----------|
| Знаки = граница | Дефис, слэш, точка — границы слова | |
| Только пробел | `привет-ghbdtn` — одно слово, заменяется целиком | |
| (free text) | «есть знаки, под которыми могут быть русские буквы — такие надо исправлять. есть знаки, под которыми букв быть не может — такие считаем за границу» | ✓ |

**User's choice:** свободная формулировка принципа владельца
**Notes:** Подтверждённая интерпретация: слово = цепочка символов с «буквенных» клавиш (позиции, где в EN или RU слое стоит буква) + внутренние цифры; всё остальное — граница.

| Option | Description | Selected |
|--------|-------------|----------|
| Входят | Цифры идут через таблицу тождественно, направление по буквам: `ghbdtn2026` → `привет2026` | ✓ |
| Обрывают слово | Двойной тап исправляет только `ghbdtn`, `2026` не трогается | |

**User's choice:** Входят

## Смешанное слово

| Option | Description | Selected |
|--------|-------------|----------|

| Только чужие буквы | `gfbпривет` при EN → `gfbghbdtn` | |

**User's choice:** Тихий отказ
**Notes:** Полная семантика отложена в Фазу 3.

| Option | Description | Selected |
|--------|-------------|----------|

| Допуск 1 буквы | До 1 «чужой» буквы слово считается однородным | |

**User's choice:** Строго
**Notes:** Нейтральные символы (цифры, общая пунктуация) смешанным слово не считают.
