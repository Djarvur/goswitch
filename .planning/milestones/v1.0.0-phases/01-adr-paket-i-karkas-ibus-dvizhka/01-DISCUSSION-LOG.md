## Тайминг тапов Right Shift

### Вопрос 1: Разрешение конфликта мгновенности и двойного тапа

| Option | Description | Selected |
|--------|-------------|----------|
| Caramba-схема | Первый тап мгновенно переключает; повторный тап в окне — коррекция. Без задержек (рекомендация исполнителя) | |
| Классика с ожиданием | После тапа ждём окно; все действия Right Shift с задержкой окна | ✓ |
| Разные клавиши | Переключение — Right Shift; коррекция — отдельная клавиша (Pause) | |

**User's choice:** Классика с ожиданием
**Notes:** Владелец выбрал вариант вопреки рекомендации; следствие (реакция Right Shift = окно, а не <50 мс) предъявлено явно и закрыто следующим вопросом.

### Вопрос 2: Окно различения и переформулировка NFR

| Option | Description | Selected |
|--------|-------------|----------|
| Окно 300 мс | Чёткие двойные тапы; NFR: «без ожидания — <50 мс; Right Shift — не дольше окна, окно настраивается» | ✓ |
| Окно 500 мс | Комфортные медленные тапы; ленивее переключение | |
| Гибрид с откатом | Свитч мгновенно, при втором тапе откат свитча и коррекция; значок мигает | |

**User's choice:** Окно 300 мс
