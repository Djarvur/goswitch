<objective>
Обратное направление правды: демон слушает шину и подтягивается под фактический активный движок (GlobalEngineChanged + FocusIn-имя → SyncEngine), а реактивация после рестарта ibus предпочитает фактический движок (GetGlobalEngine) мёртвому ключу gsettings current. Это закрывает критерий 3 («состояние демона не расходится с активным источником; sync при FocusIn») и дефект Pitfall 3 (рестарт демона молча возвращал ru-пользователя на en), и делает клик по индикатору GNOME событием, за которым демон СЛЕДУЕТ, а не воюет.

**As a** пользователь, переключивший раскладку кликом по индикатору GNOME (или пережившим рестарт ibus), **I want** чтобы демон goswitch немедленно узнал фактическую раскладку, **so that** следующий одиночный Shift и коррекция работают из правильного режима — без расхождения состояния и без войны за источник.

Purpose: INTEG-04 (перерегистрация с сохранением активного движка) + критерий 3 (sync); предпосылка для e2e-кейса external-flip-sync (05-05).
Output: подписка+диспетчер в engine, SyncEngine в акторе, IfOwned с GetGlobalEngine-приоритетом, wiring main.
