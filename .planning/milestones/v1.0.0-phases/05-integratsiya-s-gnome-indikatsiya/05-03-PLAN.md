<objective>
Механизм флипа становится видимым GNOME: все жесты переключения (одиночный Shift, Super+Space, флип после коррекции, комбо) исполняются через org.freedesktop.IBus.SetGlobalEngine на ibus-соединении демона — через один поколенческий шов BindSwitcher из engine в актора (D-52 по вердикту чекпойнта 05-01). Режим демона остаётся единственной истиной (sync-подтяжка — план 05-04), RU-commit ветка не трогается, e2e-оракуль записи mode байт-стабилен, добавлена запись switch_engine.

**As a** пользователь goswitch, **I want** чтобы каждое моё переключение раскладки реально меняло активный движок на шине IBus, **so that** ввод следующей клавиши идёт уже в новой раскладке, а GNOME (и любой наблюдатель шины) видит переключение как акт первого класса.

Purpose: SWCH-01/02/04 (механизм жестов), INTEG-01/05 (контракты движка не ломаются); фундамент для sync (05-04) и e2e-наблюдения (05-05).
Output: engine.BindSwitcher шов + константы NameEN/NameRU; actor.flipTo/SetSwitcher/Status.Engine; wiring в main; корпус порядка записей.
</objective>
