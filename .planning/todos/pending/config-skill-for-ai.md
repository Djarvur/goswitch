# Skill «Конфигурация goswitch» для AI-ассистентов

Добавить skill (формат .zcode/skills/ или .claude/skills/, SKILL.md), который
описывает: **что можно настроить** в goswitch (все секции config.yaml, goswitchctl
команды, трей-меню, юнит) и **как это сделать** — так, чтобы skill можно было
использовать как документацию по конфигурации: AI читает SKILL.md и помогает
владельцу менять настройки, не читая весь код/репо.

Содержание: секции конфига с ключами/дефолтами/диапазонами (синхрон с CONFIG.md),
процедуры (включить автокоррекцию, добавить приложение в blocklist, сменить
хоткеи, звуки, a11y-магия), диагностика (goswitchctl status, журнал, известные
ограничения). Механизм синхронизации с доками — избежать рассинхрона (генерация
из CONFIG.md или lint-гейт).
