# Перечень приложений, для которых включаем автокоррекцию a11y-магией

Нужен поддерживаемый перечень приложений, где автокоррекция требует «магии»
включения accessibility (как ZCode: toolkit-accessibility / --force-renderer-accessibility):
какие приложения известны, что для них сработало, как проверить. Форма: раздел в
документации (wiki/README) или конфиг-шаблон. Связано с reliability-настройкой
a11y-коррекций (отложено владельцем после фазы 7).
