# Конфиг-секция приложений с автоматическим включением a11y-магии

Владелец (уточнение 2026-10-05): нужен НЕ просто перечень в документах, а **секция
в конфиге**, в которой перечислены приложения, которым goswitch автоматически
включает accessibility-магию (как сделали вручную для ZCode).

Ожидаемая форма (уточнить при планировании): секция типа `a11y.apps` / расширение
`autocorrect` — список имён/паттернов приложений; демон (или установщик) сам
применяет магию для перечисленных (gsettings toolkit-accessibility, snap-оверрайды,
флаги запуска — механику исследовать). Связано: reliability a11y-коррекций,
ZCode-прецедент (подтверждён владельцем).
