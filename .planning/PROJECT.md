# goswitch

## What This Is

`goswitch` — корректор раскладки и введённого текста для GNOME Wayland (Ubuntu 24.04, T2 MacBook Pro): исправление текста, набранного не в той раскладке (EN↔RU), и переключение раскладки по горячим клавишам. Работающий демон на Go в роли **IBus input method engine** через D-Bus: коррекция слова/фразы/выделения/смешанного текста, флип раскладки, опциональная автокоррекция с чёрным списком, трей с меню, звуки, a11y-магия приложений. Опубликован: релизы v1.0.0 и v1.1.0 (GitHub releases, `go install`). Полное техническое задание: `docs/SPEC.md` (владелец Daniel Podolsky).

## Core Value

По горячей клавише исправить текст, набранный не в той раскладке (EN↔RU), в любом поле ввода GNOME Wayland — через IBus engine, без root и без конфликтов с ремапперами (keyd/xremap).

## Constraints

- **Tech stack**: Go ≥ 1.23, только stdlib + `godbus/dbus` + минимальные зависимости — простота поставки и аудита
- **Architecture**: Инъекция текста через IBus engine (`commit_text`), НЕ через uinput — не конфликтует с evdev-ремапперами
- **Architecture**: Один демон `goswitchd` — IBus engine + D-Bus сервис + наблюдение за раскладкой
- **Permissions**: Демон без root — systemd user unit
- **Performance**: Реакция < 50 мс; память < 50 МБ (достигнуто с запасом)
- **Process**: SDD (spec-driven development); изменения требований через spec-delta до кода (D-55)
- **Quality**: Автоматизированное тестирование полного цикла; ночной D-48 — формальный гейт свежей сессии
- **Licensing**: MIT, репозиторий `Djarvur/goswitch` public; conventional commits, изменения через PR

## Key Decisions

| Decision | Rationale | Outcome |
|----------|-----------|---------|
| IBus engine вместо uinput для инъекции текста | Уровень метода ввода; не требует grab; совместим с keyd/xremap | ✓ Phase 1 |
| Один демон `goswitchd`; Go (stdlib + godbus) | Простота эксплуатации; статический бинарник; минимальные зависимости | ✓ Phase 1 |
| ADR-001..005 — пакет архитектурных решений Фазы 1 | Все развилки закрыты до кода (M0-гейт, D-01 журнал) | Accepted 2026-09-10 (владелец) |
| ADR-001 ревизия → ADR-006: флип через SetGlobalEngine, двухисточниковая модель → одноисточниковая (quick 260930-toa) | GNOME 46 игнорирует gsettings-запись; goswitch-источники в sources — полноправное гражданство | ✓ Phase 5 + amendment |
| ADR-004 amendment (2026-10-07): собственный флип не сбрасывает буфер коррекции | Синтетический lifecycle-переход ≠ смена фокуса; смешанное слово через флип корректируется целиком (G-2-3, живая матрица 16/16) | ✓ quick 261008-00m |
| D-53: белый список автокоррекции → чёрный список `apps_blocklist` (regex) | Стреляет везде, где role-гейт пропускает, кроме blocklist; spec-delta до кода | ✓ Phase 7 |
| Смешанный текст = посимвольная инверсия (владелец, 2026-10-06) | Отверг freeze «флип сбрасывает контекст» (WINDOWS-12); 13 рядов матриц перепиновано | ✓ quick 261006-vqw |
| Звук: персистентный PulseAudio-стрим + тема GNOME (вместо spawn-плеера ~150 мс) | ~30 мс тон; mute = ноль соединений; spec-delta §5/§11 до кода | ✓ quick 261006-squ |

| Полуобёрнутые sources: авто-дозавернуть, при неудаче отказать (владелец, 2026-10-07) | Демон чинит конфигурацию сам; отказ только для нечерпаемого | ✓ quick 261008-00m |

| Отклонение ADR-003: фактический уровень лестницы = 1 (chromium применяет DeleteSurroundingText) | Живая находка 02-05; WINDOWS #1 | Accepted 2026-09-15 |
| GTK4-Wayland не применяет forwarded-события | Платформенное ограничение, задокументировано; WINDOWS #4 | Accepted 2026-09-15 |
