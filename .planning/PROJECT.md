# goswitch

## What This Is

`goswitch` — корректор раскладки и введённого текста для GNOME Wayland (Ubuntu 24.04, T2 MacBook Pro): исправление текста, набранного не в той раскладке (EN↔RU), и переключение раскладки по горячим клавишам. Работающий демон на Go в роли **IBus input method engine** через D-Bus: коррекция слова/фразы/выделения/смешанного текста, ручная коррекция слова в терминалах (wezterm, GNOME Terminal — собственный IBus-канал демона; автокоррекция в терминалах запрещена инвариантом), флип раскладки, опциональная автокоррекция с чёрным списком и пунктом трей-меню «в чёрный список», трей с меню, звуки, a11y-магия приложений и рецепты доступности ZCode/Telegram. Опубликован: релизы v1.0.0/v1.1.0/v1.1.1 и v1.2.0-alpha.1/2 (GitHub releases, `go install`). Полное техническое задание: `docs/SPEC.md` (владелец Daniel Podolsky).

## Core Value

По горячей клавише исправить текст, набранный не в той раскладке (EN↔RU), в любом поле ввода GNOME Wayland — включая терминалы (wezterm, GNOME Terminal) — через IBus engine, без root и без конфликтов с ремапперами (keyd/xremap).

## Constraints

- **Tech stack**: Go ≥ 1.23, только stdlib + `godbus/dbus` + минимальные зависимости — простота поставки и аудита
- **Architecture**: Инъекция текста через IBus engine (`commit_text`), НЕ через uinput — не конфликтует с evdev-ремапперами
- **Architecture**: Один демон `goswitchd` — IBus engine + D-Bus сервис + наблюдение за раскладкой
- **Permissions**: Демон без root — systemd user unit
- **Performance**: Реакция < 50 мс; память < 50 МБ (достигнуто с запасом)
- **Process**: SDD (spec-driven development); изменения требований через spec-delta до кода (D-55)
- **Quality**: Автоматизированное тестирование полного цикла; живые прогоны — только на ВМ goswitch-stand (директива владельца 2026-11-01)
- **Licensing**: MIT, репозиторий `Djarvur/goswitch` public; conventional commits, изменения через PR
