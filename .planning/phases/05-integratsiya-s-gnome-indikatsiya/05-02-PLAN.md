install перестаёт хардкодить «один хозяин» и становится обёрткой выбора пользователя (D-54): читает текущие sources, строит двухисточниковое значение из пары us/ru, честно отказывает вне пары, самозапускается идемпотентно на уже-обёрнутом столе, а uninstall по-прежнему восстанавливает оригинал дословно. selfcheck закрепляет двухисточниковое состояние (критерий 5).
