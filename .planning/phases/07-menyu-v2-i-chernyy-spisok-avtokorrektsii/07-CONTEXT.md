# Phase 7 Context — Меню v2 и чёрный список автокоррекции

## Почему эта фаза существует

Автокоррекция (фаза 6) не имеет пользовательского интерфейса: включается только правкой
YAML, а белый список требует знания «наблюдаемой» идентичности приложения (UX-пробел,
зафиксирован в 06-UAT.md). Владелец определил состав релиза v1.1.0: трей-меню v2 +
чёрный список вместо белого.

## User Constraints (решения владельца, дословно по смыслу)

- **Меню — переключение языка двумя отдельными пунктами EN и RU** «как во всех
  переключателях»: клик по пункту = включить этот язык; текущий отмечен.
- **Меню — вкл/выкл автокоррекции**: тумблер с записью в конфиг (переживает перезапуск),
  hot reload подхватывает.
- **Меню — версия приложения** (п. «О программе»).
- **Меню — клавиатурные макросы показывать сразу**: живые значения из конфига
  (tap-серия: 1 тап — язык, 2 — слово, 3 — фраза; word_layout_combo;
  mode_switch_chord), обновляются на reload конфига.
- **Меню — «Настройки…»**: запуск редактора для config.yaml (владелец: «запуск редактора
  для редактирования конфига»; все 15 ключей конфига описаны в docs/CONFIG.md —
  «важных» для меню владелец не выделил, остальное покрывает редактор).
- **Белый список НЕ НУЖЕН** («белый список не нужен»): `autocorrect.apps` удаляется из
  схемы, кода, корпуса и документации.
- **Чёрный список обязателен**: «в конфиге обязательно должен быть black list, список
  приложений, возможно, в формате regex, в которых автопереключение выключается» —
  ключ `autocorrect.apps_blocklist`, regex (подстрока; анкеровка `^…$` явная),
  совпадение = запрет автокоррекции.

- **Звуки при переключении (решение владельца 2026-10-04, «как в punto switcher и caramba»):**
  секция `sound` в конфиге — `enabled` (DEFAULT ON — владелец: «включен») и отдельное
  событие на срабатывание автокоррекции (владелец: «да» — другой звук). Воспроизведение —
  субпроцесс (canberra-gtk-play предпочтительно, paplay с комплектными .wav как фолбэк),
  no-pipes fork-shaped запуск (прецедент wl-copy/clipboard.go). Срабатывает на ЛЮБОЙ флип
  языка (Shift, пункты меню EN/RU) — демон знает о каждом флипе; отдельный тон на
  автокоррекцию. Меню: пункт-переключатель «Звук» с persist (тот же механизм, что тумблер
  автокоррекции). Hot reload, strict decode — автоматически. Чистый Go-аудио — нет
  (ограничение зависимостей).

### Claude's Discretion

- Вид представления макросов в меню (инфо-пункты vs подменю) — по эргономике DBusMenu.
- Механика persist-тумблера: атомарная правка YAML с сохранением комментариев
  (yaml.v3 Node-раундтрип) vs перегенерация — по простоте и аудируемости.
- Формат regex-матчинга: MatchString-подстрока (RE2); валидация компиляции на Load.
- Способ запуска редактора: xdg-open по умолчанию, $EDITOR при наличии.

## Owner Decisions (2026-10-04, из research open questions)

- **Adopt + watch:** на установленной системе (старт без -config) тумблер меню создаёт
  ~/.config/goswitch/config.yaml, демон начинает его смотреть; битый файл = громкий отказ
  при старте; «нет файла = дефолты» сохраняется до первого тумблера.
- **Confirm-гейт: только blocklist** — при подтверждении сверяется чёрный список текущего
  приложения; равенство «приложение арма/подтверждения» (WR-01 app-changed) удаляется —
  перенос фокуса ловит payload-stale (сверка буфера). Владелец выбрал вариант 1.

## Locked semantics (ревизия D-53 — фиксируется до кода, D-55-дисциплина)

- НОВОЕ ПРАВИЛО: автокоррекция исправляет ⇔ `enabled` ∧ живой role-гейт поля
  (текстовый ввод; пароли/терминалы — никогда) ∧ surrounding-text применим ∧
  уверенный вердикт ∧ длина ок ∧ приложение НЕ совпало с `apps_blocklist`.
- Неизвестная идентичность приложения НЕ запрет (не «молчание по D-53-unknown»):
  blocklist не может исключить то, чего не видно; полевой role-гейт остаётся
  фильтром безопасности. (Снимает и UX-пробел 06-UAT: zenity теперь стреляет.)
- Default off сохраняется (D-54): `enabled: false` + пустой blocklist.
- Ручная коррекция (Double/фраза/выделение) не ограничивается blocklist — явное
  действие пользователя.
- Спека правится spec-delta ДО кода: SPEC §11 (дополнение решения), ADR-007
  amendment (ревизия D-53: white-list → blocklist), docs/CONFIG.md, README.

## Out of Scope

- Смешанный текст (посимвольная инверсия) — отдельный backlog-план (06-UAT Deferred).
- Показ наблюдаемой идентичности в status — backlog (06-UAT Deferred); blocklist
  делает его менее критичным.
- Терминальный класс, OSD, GUI настроек — как раньше (v2).

## Технические заметки

- DBusMenu-канал и супервизор троя готовы (quick 261001-fg3, self-heal) — расширение
  меню идёт поверх существующего com.canonical.dbusmenu.
- Полевой role-гейт и 25 мс контур не трогаются (контракт фазы 6).
- Регресс: матрица v4 строки autocorrect-* перезакрепить на blocklist-семантику;
  silence-matrix юнит-корпус переработать (ячейки white-list → blocklist);
  observeFixtureApp-шов в кейсах становится не нужен для white-list (blocklist-кейсам
  нужна известная идентичность — sentinel остаётся для негативов).
