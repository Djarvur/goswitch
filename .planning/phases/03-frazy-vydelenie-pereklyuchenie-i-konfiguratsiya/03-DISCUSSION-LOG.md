## Смешанный текст

### Якорь «правильной» раскладки

| Option | Description | Selected |
|--------|-------------|----------|
| Последняя буква (Recommended) | Раскладка последней БУКВЫ буфера задаёт «правильную»; конвертируются прогоны чужих букв; цифры/общая пунктуация якорь не сдвигают. Буквальное чтение SPEC §4.2. | ✓ |
| Текущий режим демона | Якорь = EN/RU режим на момент коррекции (внутренний флип ADR-001). Ломается при переключении после набора. | |
| Большинство букв | Правильная раскладка = большинство букв токена/фразы. Не совпадает с формулировкой SPEC. | |

**User's choice:** Последняя буква
**Notes:** Закрывает Q-маркер SPEC §4.2 «определить точную семантику».
