# Requirements: goswitch — milestone v1.2 «Терминалы и видимость приложений»

**Defined:** 2026-10-08
**Core Value:** По горячей клавише исправить текст, набранный не в той раскладке (EN↔RU), в любом поле ввода GNOME Wayland — через IBus engine, без root и без конфликтов с ремапперами (keyd/xremap).

## v1.2 Requirements

Requirements for this milestone. Each maps to roadmap phases.

### TERM — Терминалы

- [ ] **TERM-01**: Переключение раскладки работает в wezterm (ежедневный терминал владельца). Живой спайк подтверждает первопричину (гипотеза: `enable_wayland = false` → wezterm как XWayland/XIM-клиент, флип движка не меняет его X-keymap — переключение структурно невидимо); фикс — рецепт нативного Wayland-режима в конфиге wezterm или демонский обход; приёмка — два подряд зелёных оракула в e2e.
- [ ] **TERM-02**: Пользователь может исправить слово не в той раскладке жестом (двойной правый Shift) в wezterm и GNOME Terminal. Чтение — собственный буфер нажатий демона (VTE) / primary-выделение (wezterm, рецепт CopyMode); запись — N×BackSpace-реплей + `commit_text` через канал IBus (не внешний инжектор, не paste), с безопасной точкой отмены до первого разрушающего действия и verify-сверкой.
- [ ] **TERM-03**: Пользователь может исправить всю набранную строку/фразу в терминале (растяжка). Feasibility-gated спайком: в VTE нет выделения с клавиатуры (VTE-исходник) — если примитив захвата строки недоступен, область честно сужается до wezterm; вердикт о сужении — за владельцем.
- [ ] **TERM-04**: Автокоррекция в терминалах никогда не срабатывает (инвариант). Вето закрепляется spec-delta (не через apps_blocklist) + замороженные негативные ряды e2e-матрицы; терминал = команды, ошибка автокоррекции недопустима.

### MENU — Меню

- [ ] **MENU-01**: Динамический пункт трей-меню «Добавить ИмяПриложения в чёрный список»: добавляет текущее наблюдаемое приложение в `autocorrect.apps_blocklist` — `regexp.QuoteMeta` имени, без дублей, потолок 64, атомарная запись конфига + живая перечитка; когда личность приложения неизвестна (wezterm/winit, snap) — пункт неактивен, демон не угадывает.

### A11Y — Видимость приложений

- [ ] **A11Y-01**: ZCode: автокоррекция работает — рецепт локального `.desktop` override с `--force-renderer-accessibility` (toolkit-accessibility через a11y-магию демона уже работает); приёмка по живому AT-SPI-дереву.
- [ ] **A11Y-02**: Telegram: автокоррекция достижима. Спайк подтверждает AppArmor-блокировку snap для входящих AT-SPI вызовов (env-рецепты не решают — доказано зондированием) и выносит решение владельца: unconfined-сборка Telegram (flatpak/deb) vs демон-fallback; при демон-fallback — отдельная приёмка с владельцем.
- [ ] **A11Y-03**: Рецепты документированы в README/CONFIG.md, включая побочный эффект Telegram (плашка «режим экранного диктора») и ограничение «флаги Electron применяются только на запуске».
